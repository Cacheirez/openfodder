Dos poses provisionales en estilo C, generadas con ImageGen integrado a partir del ciclo derecho, C01 y la silueta local de esta dirección. El arte nuevo se distribuye bajo GPL-3.0-or-later. La forma y la continuidad se valorarán jugando con las seis direcciones.

Recorte compartido `[245, 345, 1082, 875)` y colocación `[2, 3, 14, 12)` en la celda 16×14. Se usó el camino existente de `build_soldier_batch.cpp` y `build_ordered_soldier_asset.cpp`. Cada manifiesto vincula solo la clave de M1P2 confirmada al reconstruir la fila original. El original nativo queda local.
